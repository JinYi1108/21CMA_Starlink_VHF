# Key numerical results

The CSV and JSON files in this directory are the compact numerical products
used most directly in the paper. They cover:

- event timing and waterfall metadata;
- decoded-packet comparison and the Event 1 payload state vector;
- catalogue matching, analysis-weight robustness, differential Doppler, and
  SupGP validation;
- predicted orbital visibility and relative path loss;
- apparent and sidelobe-corrected flux density, EIRP, and the EDA2 comparison;
  and
- EDA2-emitter orbital-phase classifications.

Detailed diagnostic and intermediate tables remain reproducible under
`results/` and are intentionally not duplicated here.
