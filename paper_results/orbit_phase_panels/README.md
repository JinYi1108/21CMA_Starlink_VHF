# EDA2-emitter orbital histories

These seven pages show the long-term mean-altitude histories used to inspect
the orbital state of the 26 satellites associated with the EDA2 137.05-MHz
detections. Each page contains four satellite panels, except the final page,
which contains the remaining two. Detection dates are marked on the orbital
histories.

The numerical classifications and the quantities reported in the paper are
available in:

- `../key_tables/grigg2025_137p05_orbital_state_table.csv`
- `../key_tables/grigg2025_137p05_orbital_phase_summary.csv`
