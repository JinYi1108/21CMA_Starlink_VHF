# Paper results

This directory provides direct access to the principal results associated with
the paper. The files are curated convenience copies of products generated by
the notebooks; a fresh run continues to write its complete output under
`results/`.

## Contents

- `demodulation/`: the decoded frame and payload, frame table, diagnostic plot,
  and complete decoder summary for each of the two detected packets.
- `key_tables/`: selected numerical results used directly in the paper,
  covering the waterfalls, packet comparison, satellite identification,
  differential Doppler test, SupGP validation, orbital visibility,
  flux-density estimate, EIRP estimate, EDA2 comparison, and orbital-phase
  re-analysis.
- `orbit_phase_panels/`: the seven four-panel pages showing the long-term
  orbital histories of all 26 EDA2 satellites included in the 137.05-MHz
  re-analysis.

Large intermediate arrays, diagnostic-only products, and duplicate working
files are deliberately omitted from this directory.
