# Input data

This directory contains only inputs that cannot be generated by an earlier
step of the repository workflow.

- `raw/`: the two public 21CMA voltage files from Zenodo record 23309576.
- `observation/`: fixed acquisition UTC metadata. These timestamps replace
  the original recorder filesystem modification times, which do not survive
  a download from Zenodo.
- `station/`: 21CMA pod element coordinates used to construct the E08 station
  centre and idealised array-factor model.
- `orbital/`: catalogue TLE, historical TLE, and SpaceX-E SupGP snapshots used
  in the paper analysis.
- `maps/`: Natural Earth coastline geometry used by the trajectory figure.
- `external/`: included third-party inputs used by the EDA2 comparison and
  orbital-phase analysis, with provenance documented per directory.

Generated products belong under the top-level `results/` directory and are
ignored by Git.
